# Robot SLAM Autonomous Navigation

Simultaneous Localization and Mapping (SLAM) for autonomous robot navigation.

## Features
- EKF-SLAM with Extended Kalman Filter
- Particle Filter SLAM (Monte Carlo localization)
- Occupancy Grid Mapping (2D environment)
- A* Path Planning
- Dynamic Obstacle Avoidance

## Hardware Support
- TurtleBot3 (Burger/Waffle)
- Unitree Go2 quadruped
- Generic ROS2-compatible robots
